# Dice-Roll-2

A simple, browser-based Dice Roll app built with HTML, CSS and JavaScript.

![App Screenshot](./Screenshot%202025-10-24%20at%2014.48.38.png)

Live demo
- Open `index.html` in your browser to try the app locally.

What it does
- Simulates rolling a six-sided die.
- Displays the result clearly on the page with a single click.

Files
- `index.html` — the full app (HTML, CSS, and JavaScript embedded).
- `Screenshot 2025-10-24 at 14.48.38.png` — screenshot used above.

How to run
1. Clone or download the repository.
2. Open `index.html` in your preferred web browser (no server required).

Notes
- This project is intentionally small and dependency-free to make it easy to inspect and learn from.
